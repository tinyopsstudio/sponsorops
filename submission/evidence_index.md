## Private evidence candidates

- private payment screenshot retained outside the submission packet
- privacy-safe revenue reconciliation PDF with private source SHA-256 fingerprint
- redacted customer correspondence chronology
- articles of organization
- Google Cloud cost table or zero-dollar invoice
- Vertex AI model observability dashboard
- Cloud Run request and latency dashboard
- Cloud Logging structured decision events

## Public evidence candidates

- live SponsorOps Cloud Run service
- public source repository
- SponsorOps dashboard
- privacy-safe sponsor fulfillment case study at https://tinyopsstudio.com/troutmate-sponsor-fulfillment-case-study
- public sponsored article and deployment QA evidence

## Privacy rules

- remove owner name and residential address from public evidence
- remove bank account, routing, card, and transaction identifiers
- remove customer contact names, personal email, phone, and message IDs unless explicit consent is received
- keep only the public advertiser business name where necessary and appropriate
- use a one-way opportunity hash in execution logs
